# Cognitive Skills Framework

This book introduces cognitive transformations a language model may perform and shows how they can be organized into useful methods. The repository's modules are examples a designer can inspect, adapt, or combine when developing an application.

The reading path begins with simple relationships, then develops further operations and their combinations before turning to the tools. The examples make the underlying ideas available for discussion; model capabilities and reliability can vary.

## The book

| Part | Starting page | What it develops |
|---|---|---|
| Foundations | [1. Overview and Basics](docs/chapters/01_OVERVIEW_AND_BASICS.md) | Analogy, metaphor, viewpoint, abstraction, salience, inversion, and reversibility. |
| Working with transformations | [2. Compound Transformations](docs/chapters/02_WORKING_WITH_TRANSFORMATIONS.md) | Further operations, recurring combinations, and the organization of a useful method. |
| Representing and reusing a thought | [O/D/R/O](docs/ODRO.md), then [KCE](docs/skills/KCE.md) | The relationships a transformation should preserve and the movement between a particular case and a reusable concept. |
| Tools | [Framework overview](docs/tools/00_FRAMEWORK_OVERVIEW.md) | The available modules, their purposes, and the individual tool guides. |

The [book design](docs/BOOK_DESIGN.md) describes the developing editorial structure. Existing reader guides provide starting pages for the tools; the [module index](docs/MODULES.md) links the detailed specifications and templates.
